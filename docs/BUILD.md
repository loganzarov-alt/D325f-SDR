# Build, test and signing

Use Linux x86_64, JDK 17, Python 3, Android platform 34, build-tools 35.0.0,
NDK 27.2.12479018 and CMake 3.22.1. Set `JAVA_HOME` and `ANDROID_HOME`.

```sh
./gradlew --no-daemon :app:assembleRelease :app:testReleaseUnitTest
bash tools/verify-host.sh
```

The APK is `app/build/outputs/apk/release/app-release.apk`. All five custom
executables are generated by `native/build_helpers.py`; interface stubs for QMI
are link inputs only and never packaged. Runtime uses vendor QMI libraries.

## Signing and updates

Without signing secrets, release is test/debug-signed. The first public APK uses
a dedicated release certificate. CI runners can produce different certificates,
preventing updates over an APK signed with another key.

A stable distribution key can be supplied with `D325F_KEYSTORE`,
`D325F_STORE_PASSWORD`, `D325F_KEY_ALIAS` and `D325F_KEY_PASSWORD`. Keep these
outside git. CI here intentionally produces test-signed artifacts only; no public
release or signing secret is created by the build workflow. Preserve device data
before changing installation/signing arrangements.

Package ID is `io.github.loganzarov_alt.d325fsdr`, versionName `1.0.1`,
versionCode `2`. It installs separately from the development app; there is no
in-place upgrade or automatic settings import. Existing IQ files can be opened
with the system file picker. Internal Java package names retain upstream names
for provenance. Legacy recording-format IDs remain readable; CI8 maps explicitly
to signed 8-bit samples.

## Optional reference-based native test

The original reference ELF is deliberately not distributed. Supply the owner's
original APK locally:

```sh
python3 tools/extract-reference.py /path/to/RF-Decoder-from-LG-v20058-20261023.apk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.2.12479018"
python3 native/from-source/tests/build-oracle.py
qemu-arm native/from-source/build/oracle native/from-source/reference/lg_stream-rxfix3
```

This runs 4,272 cases against mocked hardware calls. CI compiles the oracle but
does not claim to run the differential cases without the external reference.
