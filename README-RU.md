# D325f-SDR

Первый публичный выпуск: **1.0.0**, код версии **1**. ARMv7, Android 7.1+.

Экспериментальный SDR на встроенном сотовом модеме LG D325. Проект и интеграция
модемной части — Logan Zarov. Репозиторий сейчас содержит приложение и его
userspace-helper программы. Исходники приложения включают код RF Analyzer
Dennis Mantz и других авторов; это отражено в About и [лицензиях](LICENSING.md).

Источников два: **модем LG** и **IQ-файл**. Поддержка внешних HackRF/RTL-SDR
удалена. Старые форматы IQ-записей сохранены; это не поддержка USB-устройств.

## Сборка

Linux x86_64, JDK 17, Python 3, Android SDK; Gradle 8.13 запускается wrapper:

```sh
sdkmanager "platforms;android-34" "build-tools;35.0.0" \
  "ndk;27.2.12479018" "cmake;3.22.1"
export ANDROID_HOME=/путь/к/android-sdk
./gradlew --no-daemon :app:assembleRelease :app:testReleaseUnitTest
```

APK: `app/build/outputs/apk/release/app-release.apk`.
[Подробнее о сборке и подписи](docs/BUILD.md).

## Проверенное и ограничения

Предыдущую сборку v20058 из исходников владелец проверил на своём подготовленном
LG и сообщил, что она работает. Публичная редакция 1.0.0 меняет оформление,
лицензионные уведомления и список источников; ей нужна новая проверка на телефоне.
Журналы host-тестов и компиляции отделены от сообщения владельца об аппаратной проверке.

Все пять собственных native-helper программ компилируются из C/ASM, DSP — из
C++. Готовый lg_stream не используется при сборке. Исходник lg_stream является
реконструкцией; совпадение APK/ELF байт в байт не заявляется. Исторические 4272
сравнительных случая в QEMU — не аппаратный тест и не доказательство полной эквивалентности.

Проприетарные прошивки модема и системные QMI-библиотеки не входят в исходники.
Готовой проверенной инструкции подготовки второго штатного телефона ещё нет:
[статус](docs/DEVICE-SETUP.md). APK сам по себе такую подготовку не выполняет.
