LG D325 Modem Patcher 1.0.4 / TWRP Toggle 1.1

Это инструмент обратимого изменения файлов модема на LG D325 (w5ds).
Публичный комплект содержит исходники инструмента, XOR-маски, смещения
относительно файлов и SHA-256 поддерживаемых версий. Полные образы модема,
boot.img, IMEI, калибровки, закрытые SDK и ключ подписи в него не включены.
Наличие дельты само по себе не устанавливает право её распространения.

APK
Установите Modem-Patcher-LG-D325-v1.0.4.apk и разрешите root в менеджере su.
«Проверить» читает настоящий modem-раздел без записи.
«Пропатчить модем» применяет патч; «Восстановить сток» обращает его.
При неподдерживаемой прошивке или смешанном состоянии запись запрещена.
Восстановление исходных файлов не требует заранее сохранённого бэкапа.
Результат проверяется повторным чтением. Перезагрузка — отдельная кнопка.
Обработка 64-МиБ образов происходит в нативном процессе, без больших
Java-массивов и без передачи бинарных данных через stdout команды su.
Для старого APK с другой подписью потребуется удаление перед установкой.

TWRP
ZIP прошивается из TWRP. Первое применение к стоку устанавливает патч,
повторное применение удаляет его. Телефон автоматически не перезагружается.
Проверяются модель, единственность modem-раздела, размер 64 МиБ, FAT
и хеши шести затрагиваемых файлов. Раздел ищется по смонтированной
firmware и метке modem, без фиксированного номера mmcblk0pN или серийника.
Другой LG D325 с теми же хешами поддерживается независимо от расположения
файлов в FAT. Фрагментированные файлы отклоняются. На другом телефоне
физическая проверка не проводилась.
Затрагиваются только изменившиеся секторы modem. boot, modemst1/2,
persist, fsg и персональные калибровки в других разделах не переписываются.
При ошибке записи выполняется попытка вернуть исходные изменённые секторы
с проверкой. Отключение питания во время записи этим не страхуется.

Температура
Запись начинается при температуре обоих CPU-датчиков ниже 48 °C;
перед записью проверяется порог 58 °C при пользовательском лимите 60 °C.
Проверка только чтением доступна без этого условия.

Точность восстановления
Восстанавливаются исходные версии шести файлов по их SHA-256.
Непатченные данные и FAT-метаданные сохраняются. Поэтому полученный
сток не обязан целиком совпадать с образом от другого телефона/бэкапа.
Два последовательных переключения исправного образа этим инструментом
возвращают исходный образ побайтно, что проверено на тестовых копиях.

Проверки
В reports находятся результаты проверок на файлах-копиях и на LG.
При проверках APK реальный раздел использовался только для чтения.
Прошивка TWRP ZIP на реальном разделе пока не проверена.
При публикации дополнительно пройдены 13 host-тестов на искусственных
FAT-образах: python3 tests/host-synthetic.py. Реальные разделы не затрагивались.

Сборка
Нужны Python 3, JDK с javac/keytool, Android SDK android.jar, aapt,
zipalign, apksigner, R8/D8 JAR, qemu-arm и ARM GCC/binutils.
SDK, R8, JDK, GCC и системные программы не входят в архив и устанавливаются
отдельно с соблюдением их лицензий.
1. sh recovery/build-runtime.sh
   musl-1.2.5.tar.gz включён без изменений, SHA-256 проверяется скриптом.
2. python3 recovery/build-zip.py
3. ANDROID_JAR=/path/to/android.jar R8_JAR=/path/to/r8.jar python3 build.py
   Без LG_PATCHER_KEYSTORE создаётся свой локальный ключ build/local-signing.keystore.
   Для обновления уже установленного APK используйте тот же свой ключ.
4. Сборка теста: с теми же переменными python3 tests/build-tests.py
   Тест содержит проверки только известных эталонных копий и устанавливается
   отдельно; обычному пользователю он не нужен. На исходном другом модеме
   ожидаемый полный SHA-256 теста нужно адаптировать.
5. Тест нативного модуля: STOCK_IMAGE=/path/stock.bin
   WORKING_IMAGE=/path/patched.bin python3 recovery/test-toggle.py
   Образы должны быть вашими личными файлами; в архив они не входят.

Состав кода и лицензии
Нативный модуль связан с musl (MIT и совместимые разрешительные лицензии)
и вспомогательным runtime GCC с GCC Runtime Library Exception.
Уведомления находятся в licenses и в собранных APK/ZIP.
Исходный архив musl находится в third_party для воспроизведения сборки.
Собственный код и документация патчера опубликованы в составе D325f-SDR
под GPL-3.0-or-later. Текст лицензии — LICENSE, состав и условия — LICENSING.md.
При разработке кода и документации использовались инструменты ИИ.
Образ boot.img — отдельный личный бэкап, не часть проекта патчера.
Ядро Linux распространяется по GPLv2; для публикации готового ядра нужны
соответствующие исходники, изменения и скрипты сборки по условиям GPL.
Лицензии остальных компонентов boot.img проверяются по их составу.
