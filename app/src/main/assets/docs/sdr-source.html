Signal source

LG D325 modem provides native IQ. Auto PLL chooses a profile by frequency; sensitivity depends on the physical RF path. The BT receive limit is configurable (default 800 MHz); changes apply after stopping and restarting RX. IQ File opens interleaved signed 8-bit (CI8), unsigned 8-bit (CU8) or little-endian signed 16-bit (CI16) samples. CI8 (legacy) is an alias for older stored recordings. Enter the file sample rate and centre frequency. Repeat rewinds at end of file. External USB receivers and rtl_tcp are not supported.
