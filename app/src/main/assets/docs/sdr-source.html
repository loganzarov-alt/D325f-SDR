Signal Source

LG D325 reception requires root and a compatible modified kernel and modem. Installing this APK does not prepare a stock phone. Choose a source and start reception.

IQ files support CI8 (signed 8-bit), CU8 (unsigned 8-bit) and CI16 (signed 16-bit, little-endian). Enter the recorded sample rate and centre frequency. CI8 legacy uses the same signed format.

Auto chooses the PLL profile by frequency. Profile 500 is not used because stable PLL lock has not been confirmed.

Enter 1–2402 MHz (default 1000). Below this limit reception uses the BT oscillator; at or above it reception is direct. Stop and restart RX after saving.

Below the BT receive limit: modem frequency = (2402 + BT channel) MHz minus receive frequency. At or above the limit, reception is direct.

Invert IQ spectrum

5 MHz: native 7.68 MS/s; 2 MHz: FIR /3, 2.56 MS/s; 1 MHz: FIR /6, 1.28 MS/s. Manual raw IQ recording uses 7.68 MS/s; automated recording uses the selected rate. Freeze pauses the spectrum and waterfall while audio remains available.
