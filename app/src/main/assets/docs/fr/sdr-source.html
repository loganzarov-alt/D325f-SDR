Source du signal

La réception LG D325 nécessite root et un noyau et modem modifiés compatibles. Installer cet APK ne prépare pas un téléphone d’origine. Choisissez une source et démarrez la réception.

Les fichiers IQ acceptent CI8 (8 bits signés), CU8 (8 bits non signés) et CI16 (16 bits signés, petit-boutiste). Saisissez le taux d’échantillonnage et la fréquence centrale de l’enregistrement. CI8 legacy utilise le même format signé.

Auto choisit le profil PLL selon la fréquence. Le profil 500 est exclu car un verrouillage PLL stable n’a pas été confirmé.

Saisissez 1–2402 MHz (par défaut : 1000). Sous la limite, réception avec oscillateur BT ; à partir de la limite, réception directe. Arrêtez puis relancez RX après enregistrement.

Sous la limite BT RX : fréquence du modem = (2402 + canal BT) MHz moins la fréquence de réception. À partir de la limite, la réception est directe.

Inverser le spectre IQ

5 MHz : 7,68 Méch/s natifs ; 2 MHz : FIR /3, 2,56 Méch/s ; 1 MHz : FIR /6, 1,28 Méch/s. L’enregistrement IQ manuel utilise 7,68 Méch/s ; l’automatique utilise le taux choisi. Figer suspend le spectre et la cascade ; l’audio reste disponible.
