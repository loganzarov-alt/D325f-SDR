訊號源

LG D325 接收需要 root 權限以及相容的已修改核心和數據機。僅安裝此 APK 無法改裝原廠手機。選擇來源並啟動接收。

IQ 檔案支援 CI8（有號 8 位元）、CU8（無號 8 位元）和 CI16（有號 16 位元，小端序）。請輸入錄製時的取樣率和中心頻率。CI8 legacy 使用相同的有號格式。

Auto 依頻率選擇 PLL 設定。設定 500 未使用，因為尚未確認其 PLL 能穩定鎖定。

輸入 1–2402 MHz（預設 1000）。低於此上限時使用 BT 本振；達到或高於上限時直接接收。儲存後請停止並重新啟動 RX。

低於 BT 接收上限時：數據機頻率 = (2402 + BT 通道) MHz 減去接收頻率。達到或高於上限時直接接收。

反轉 IQ 頻譜

5 MHz：原始 7.68 MS/s；2 MHz：FIR /3，2.56 MS/s；1 MHz：FIR /6，1.28 MS/s。手動原始 IQ 錄製使用 7.68 MS/s，自動錄製使用所選取樣率。凍結會暫停頻譜和瀑布圖，音訊仍可使用。
